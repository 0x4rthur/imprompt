# Imprompt 0.1.2

This release fixes provider connections and updates model selection with economical
options, reference prices and suggestions for everyday text editing.

## Fixed

- Models such as GPT-5.6 Luna no longer receive unsupported sampling parameters.
- Provider connections support OpenAI Chat Completions, OpenAI Responses and native
  Anthropic Messages, including custom model IDs and local servers.
- Changing tabs or switching providers preserves your draft configuration. Failed
  connection tests keep the previously working configuration active.
- API keys are stored separately for each endpoint in the system credential vault.
  The existing key is migrated to the endpoint already configured in your app.
- Connection status ignores outdated test results and handles provider errors more clearly.

## Updated

- 18 curated options across OpenAI, Anthropic, OpenRouter, DeepSeek, Gemini and xAI,
  checked on September 22, 2026. Includes GPT-5.6 Luna, Claude Sonnet 5, DeepSeek
  V4.1 Flash, Gemini 3.5 Flash-Lite, Gemini 3.8 Flash and Grok 4.7.
- The footer estimates the selected model's cost using an explicit example of
  1,000 input and 500 output tokens, instead of always referring to GPT-4o Mini.
- Quality, speed and cost indicators are available for every selection, including
  GPT-5.6 Luna. Published Artificial Analysis scores and throughput include their
  reference variant, source, date and grading criteria. Unverified measurements
  (including Qwen 3.5 Flash) are labeled unavailable rather than invented.
- The usage estimate shares the model catalog, preserves custom price overrides
  and handles Gemini's announced January 2027 price change.
- Signed Windows updater assets and `latest.json` are included in this release.
- **About → Updates** shows the installed version, checks for releases, and offers
  download, signature verification, installation and restart with progress. The app
  also checks at startup and every six hours, notifying when a new version appears.

Existing saved model IDs remain unchanged. Recommendations are editorial choices
based on published pricing and model positioning, not measured performance rankings.
Model availability and billing depend on your provider account.

## Install or update — Windows x64

Download **Imprompt_0.1.2_x64-setup.exe** from this release and run it to update
your existing installation. You can also use **Check for updates** from the
Imprompt tray menu, or **About → Updates** in Preferences, then **Download and restart**.

The `.sig` file is the Tauri updater signature. `SHA256SUMS.txt` contains artifact
checksums; `latest.json` is used by the automatic updater. The updater signature
is separate from Windows Authenticode publisher signing.

Validation: 94 local automated tests, TypeScript checking, Rust formatting and
Clippy, signed production build and visual review. Tests use local
mock APIs; they do not verify access to every paid provider account.
