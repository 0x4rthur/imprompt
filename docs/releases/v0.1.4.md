# Imprompt 0.1.4

- Renames **About** to **Settings** (**Configurações** in Portuguese) in navigation
  and the home shortcut.
- Replaces the information symbol with a gear that turns briefly on hover or
  keyboard focus. Respects the system's reduced-motion preference.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.4_x64-setup.exe**. The signed updater files and checksums are included.

Validation: frontend tests and TypeScript, visual and keyboard checks in both
languages, reduced-motion preview, production build and updater signature checks.
