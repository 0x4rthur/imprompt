# Imprompt 0.1.8

- The preferences window now has a fixed size (900×640), so nothing gets
  squeezed or stretched out of place.
- Home fits the window without scrolling, and long values on the quick tiles
  (like "Corrigir & clarear") wrap to two lines instead of being cut.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.8_x64-setup.exe**.

Validation: frontend tests (70) and TypeScript, Rust fmt/clippy/tests, production
build, and a visual check of every tab at 900×640.
