# Imprompt 0.1.15

- In the popup, the preset you pick last is the one that counts. Before, if you
  clicked a preset with the mouse, then picked another one with its number key
  and pressed Enter, the popup went back to the preset you had clicked and
  pasted its result. This happened both while the first result was still
  loading and after it was on screen.
- The same rule holds when a preset only has keyboard focus (Tab): a number key
  pressed afterwards wins.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.15_x64-setup.exe**.

Validation: frontend tests (117) and TypeScript, Rust fmt/clippy/tests (109),
production build, and the sequence above replayed with real clicks and keys in
a browser (mouse then number, mouse then mouse, result already on screen,
keyboard only).
