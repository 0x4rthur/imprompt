# Imprompt 0.1.14

- Imprompt now notices when Windows has turned its startup off. Windows keeps
  its own switch for each startup app (Task Manager → Startup apps, or
  Settings → Apps → Startup). When that switch was off, Settings still showed
  "Start with the system" as on, and the app never opened with the computer.
- When that happens, Preferences shows a warning with two choices: **Turn back
  on** (Imprompt opens with the system again) or **Keep it off** (the option is
  switched off, and the warning goes away).
- The "Start with the system" switch now shows what really happens, and it is
  checked again every time you open Preferences.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.14_x64-setup.exe**.

Validation: frontend tests (113) and TypeScript, Rust fmt/clippy/tests (109),
production build, and a read-only check against a real Windows registry where
the startup was disabled.
