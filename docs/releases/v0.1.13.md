# Imprompt 0.1.13

- The result is only pasted where the text came from. If you switch windows
  while the API is answering, nothing is pasted over there: the result stays on
  the clipboard and a notification tells you to press Ctrl+V.
- In Instant mode, Ctrl+C twice with nothing selected no longer sends whatever
  was on the clipboard before. In Popup mode the popup still opens, because you
  see the text before sending it.
- Pasting now works with non-Latin keyboard layouts (Russian, Greek, Hebrew).
- A settings, presets or usage file saved with a byte-order mark (Notepad and
  PowerShell do this) is read normally instead of being treated as unreadable.
- For developers: an end-to-end test presses the real shortcut and checks the
  real paste (`scripts/e2e/run.ps1`), and the data folder can be redirected with
  `IMPROMPT_CONFIG_DIR`.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.13_x64-setup.exe**.

Validation: frontend tests (107) and TypeScript, Rust fmt/clippy/tests (107),
production build, and the end-to-end paste test on the release executable
(instant, popup, no selection, window switch): 5 of 5.
