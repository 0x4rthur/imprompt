# Imprompt 0.1.12

A full review of the app: the popup keeps up with you, results are no longer
damaged on the way back, and the first use after startup is faster.

**Popup**
- Press Enter twice quickly and the result is applied as soon as it arrives
  (the footer says "applies when ready"; Esc or clicking another window cancels).
  Before, the second Enter was lost.
- Changing the preset after a result (or while one is loading) refines again
  with the new preset right away. Before, Enter pasted the previous preset's
  result.
- A late answer can no longer land on the wrong text, and presets you create,
  delete or translate show up the next time the popup opens.
- Enter keeps advancing after a mouse click on Copy or Expand, and does nothing
  while the popup is closing.

**Results**
- The clean-up of the model's answer no longer deletes real content: replies
  that start with "Sure," or "Claro!", leading `**`, `##` or `-`, quoted
  phrases and code that starts with `#` now arrive intact. Reasoning that some
  models return inside `<think>` tags is removed.
- A selection that ends with a line break keeps it when the result is pasted.
- A copy of the Reply preset behaves like Reply (it is copied, never pasted
  over the message).

**Speed**
- The popup and the "Imprompting" window are prepared when the app starts, and
  opening the popup opens the connection to your provider ahead of time (no
  text and no key are sent for that).

**Reliability**
- Holding the shortcut no longer triggers Imprompt; only a real double tap does.
- Clearer API errors: an account without credit says so instead of "try again
  shortly", Gemini's error format is understood, and output cut by a content
  filter is not delivered as complete.
- Instant mode and Undo tell you when pasting failed; Undo restores the text of
  the last result you actually applied.
- If a settings, usage or presets file cannot be read, a `.corrupt` copy is kept
  before defaults take over.
- Preferences: the connection status recovers on its own after a failure,
  presets follow the app language, the balance is requested less often and never
  shows the previous provider's, the shortcut recorder works on AZERTY and
  Dvorak, delete errors are shown, and tabs open at the top.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.12_x64-setup.exe**.

Validation: frontend tests (107) and TypeScript, Rust fmt/clippy/tests (104),
production build, the popup and every tab in a real browser, and a dev run
confirming the windows are prepared at startup.
