# Imprompt 0.1.12

- The popup now keeps up with you. Press Enter twice quickly and the result is
  applied as soon as it arrives (the footer says "applies when ready"; Esc
  cancels). Before, the second Enter was lost.
- Changing the preset after a result (or while one is loading) refines again
  with the new preset right away. Before, Enter pasted the previous preset's
  result.
- A late answer can no longer land on the wrong text: it is discarded after
  Esc, a preset change, or a new capture.
- Faster first use: the popup and the "Imprompting" window are prepared when
  the app starts, and opening the popup opens the connection to your provider
  ahead of time (no text and no key are sent for that).
- Holding the shortcut no longer triggers Imprompt; only a real double tap does.
- Instant mode and Undo now tell you when pasting failed instead of failing
  silently. The "Imprompting" window is positioned correctly on scaled displays.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.12_x64-setup.exe**.

Validation: frontend tests (87) and TypeScript, Rust fmt/clippy/tests (84),
production build, the popup flows in a real browser, and a dev run confirming
the windows are prepared at startup.
