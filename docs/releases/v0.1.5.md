# Imprompt 0.1.5

- Follows the system theme: light or dark in Preferences, the popup and the
  "Imprompting…" loader, with readable contrast in both.
- Clearer screens: every tab has a title and a one-line description; sections are
  easier to scan; help text uses the system font while labels and values keep the
  monospaced look.
- One set of controls: a switch for every on/off setting, a segmented track for
  choices, and preset chips with a color dot.
- Home shows a setup prompt when the API is not connected and a "Your setup"
  summary. History entries can copy the result.
- API: provider, model, key and speed in separate sections; the privacy note sits
  next to the provider; "Apply and test" stays visible at the bottom.
- Popup: actions in a fixed footer, a loading placeholder while refining, and
  Enter now activates a focused Copy or Apply button.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.5_x64-setup.exe**.

Validation: frontend tests and TypeScript, production build, visual checks in both
themes and both languages, and a run in the desktop window.
