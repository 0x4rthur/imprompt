# Imprompt 0.1.11

- New **Reply** preset: select a message you received (an email, a chat
  message, a comment), press Ctrl+C twice and pick Reply (key 7 in the popup).
  Imprompt writes your answer in the message's language, matching its tone,
  formality and length, answering every point. Where only you know the answer
  (a date, an amount, a yes or no), it leaves a [placeholder] for you to fill in.
- A reply always goes to the clipboard, even with "Replace" on, so it never
  overwrites the message you received. Paste it with Ctrl+V where you're
  answering.
- The default-preset tiles in Presets now fit seven in one row.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.11_x64-setup.exe**.

Validation: frontend tests (79) and TypeScript, Rust fmt/clippy/tests (82),
production build, and a visual check of the popup and the Presets tab.
