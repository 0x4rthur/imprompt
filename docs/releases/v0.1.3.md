# Imprompt 0.1.3

Faster prompt refinement across providers, without changing your selected model.

- **Prioritize speed** is enabled by default, including existing installations.
  Known models use their lowest supported reasoning effort: GPT-5 Nano uses
  minimal, GPT-5.6 Luna/Terra disable reasoning, and other supported providers use
  their documented controls. Disable it in the API tab for complex reasoning.
- Preserves every built-in prompt, example and output-format instruction from
  0.1.2, along with user-edited presets. Speed controls do not change their purpose.
- Reuses idle HTTP connections for longer when the server permits.
- If a provider explicitly rejects an optional speed control, retries once
  without it and remembers compatibility for that session. Unknown deployments
  keep their API defaults. No premium processing tier is enabled.

Actual latency still depends on the model, output length, network and provider
load. Reduced reasoning can affect complex tasks. No fixed speedup is claimed.
In a six-call GPT-5 Nano sample with unchanged prompts, mean time fell from
10.36 s to 1.99 s; this is a small sample, not a guarantee or a cross-provider benchmark.
See [latency controls and sources](https://github.com/0x4rthur/imprompt/blob/v0.1.3/docs/LATENCY.md).

Update using **About → Updates → Download and restart**, or run
**Imprompt_0.1.3_x64-setup.exe** from this release. The `.sig` and `latest.json`
files support the in-app updater; `SHA256SUMS.txt` lists the artifact checksums.

Validation: automated Rust and frontend tests, TypeScript checking, Rust formatting
and Clippy, production build and updater signature verification. Automated API
transport tests use local mock servers; a separate opt-in live A/B used synthetic
inputs and the configured GPT-5 Nano account.
