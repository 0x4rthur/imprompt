# Imprompt 0.1.18

The popup now follows one simple rule, all on the Enter key.

- **Picking another preset only selects it.** The result of the previous preset
  leaves the screen and nothing is generated on its own.
- **Enter generates with the selected preset** when there is no result for it
  yet.
- **Enter again, on the same preset, inserts the result.**

Until 0.1.17, picking another preset generated again by itself. The Enter you
pressed to say "generate with this one" then found the new result already there
and was read as "insert". That is why it looked as if the preset change had
been ignored.

Also in this version:

- If you keep pressing Enter, nothing is inserted until the keys have stopped
  for 0.6 s, so no Enter lands in the app underneath. The first Enter generates
  with the new preset and the following ones insert its result.
- Redo (R) while an insert is pending asks for a new result and waits for Enter.
- The popup keeps a small diagnostic file, `popup-trace.log`, in the app's data
  folder: keys, chosen presets and timings of each opening. It never contains
  your text or the result, and it stays on your computer.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.18_x64-setup.exe**.

Validation: frontend tests (126) and TypeScript, Rust fmt/clippy/tests (113),
production build, and the sequences above replayed in a browser with real keys
and clicks at a human pace (one Enter every 0.3 s) against a simulated API.
