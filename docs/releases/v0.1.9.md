# Imprompt 0.1.9

- The side menu now runs the full height of the window, flush with its edges.
- Settings and Shortcut fill the window: cards stretch to the bottom, the
  update button sits at the foot of its card and the delay slider spans the card.
- The active tab's icon keeps its animation's end state (the API plug stays
  connected while you're on API), and so does the selected provider's logo.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.9_x64-setup.exe**.

Validation: frontend tests (70) and TypeScript, Rust fmt/clippy/tests, production
build, and a visual check of every tab at 900×640 in both themes.
