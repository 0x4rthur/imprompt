# Imprompt 0.1.19

Updating no longer gets stuck on a slow or unstable connection.

- **Always straight to the newest version.** "Download and restart" has always
  fetched the latest release, whatever version the screen was offering; there is
  no need to install the versions in between. The screen now shows the version
  it is really downloading, instead of the older one it found earlier.
- **A stalled download is tried again.** An attempt is dropped if it cannot
  connect within 15 seconds or receives nothing for 25 seconds, and the download
  is tried up to three times. Before, it could sit on "Downloading…" for five
  minutes.
- **The screen says what is happening.** During a retry it shows "the connection
  dropped, attempt 2". If every attempt fails, the message says so in plain
  words, nothing is changed on your computer, and you can try again.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.19_x64-setup.exe**.

Validation: frontend tests (131) and TypeScript, Rust fmt/clippy/tests (117),
production build, and a simulated dropped download checked in a browser. The
new timeouts were not exercised against a real stalled connection.
