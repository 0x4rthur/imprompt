# Imprompt 0.1.10

- See your API balance: with **DeepSeek** the API tab shows your account
  balance; with **OpenRouter** it shows what's left on your key (or what it has
  spent, when the key has no spending limit). For OpenAI, Anthropic, Gemini and
  xAI, which don't share the balance with apps, there's a link to the
  provider's billing page.
- Low balance warning: when the balance drops below about $1, the API tile on
  Home turns amber and shows how much is left.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.10_x64-setup.exe**.

Validation: frontend tests (77) and TypeScript, Rust fmt/clippy/tests (79),
production build, and a visual check of Home and the API tab.
