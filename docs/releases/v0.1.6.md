# Imprompt 0.1.6

- Faster popup flow: Ctrl+C, Ctrl+C, Enter to refine, Enter again to apply.
  Redo moved to the R key. After an error, Enter tries again.
- Presets no longer shorten your text: every detail, requirement, name and number
  is carried into the rewritten prompt, even for long or dictated input.
- New "Summarize" preset for when you do want a shorter version.
- "Front-end" is now "Vibe Code", with a stronger default that turns long,
  multi-part requests into numbered items so nothing is dropped. If you edited this
  preset before, use Presets → Restore defaults to get the new version.
- Theme choice in General: System, Light or Dark, applied to Preferences, the popup
  and the loader.
- The popup window has minimum and maximum sizes, so it can no longer be squeezed
  until the content disappears or stretched across the screen.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.6_x64-setup.exe**.

Validation: Rust fmt, clippy and tests; frontend tests and TypeScript; production
build; theme switching checked in the browser.
