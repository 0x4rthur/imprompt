# Imprompt 0.1.16

Pressing Enter many times in the popup no longer sends your original text.

- When the popup closed while you were still pressing Enter, the next Enter
  landed in the app underneath. In a chat, that sent the text you had selected,
  unrefined. Now nothing is pasted while Enter is still being pressed: the popup
  waits until the keys have stopped for about a third of a second.
- After you switch to another preset, Enter means "generate with this one". The
  new result always shows up first and waits for one more Enter, pressed after
  you have seen it. Before, Enter pressed while the new preset was loading
  pasted the result the moment it arrived.
- On the same preset nothing changes when you type normally: Ctrl+C twice,
  Enter, Enter still pastes the result as soon as it arrives.

Update from **Settings → Updates → Download and restart**, or run
**Imprompt_0.1.16_x64-setup.exe**.

Validation: frontend tests (121) and TypeScript, Rust fmt/clippy/tests (109),
production build, and the sequences above replayed with real clicks and keys in
a browser against a simulated API.
